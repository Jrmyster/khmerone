Seven local activities, five external resources

Six activities use the open-source runtimes below. The seventh is an original simplified eye-focusing lesson, with a separate link to the gkaModelEye MATLAB research repository. The downloadable activity pack does not install the five external resources or MATLAB.

Khmer translations are drafts for teacher review. The illustrated book, evidence activity, coding missions, vocabulary explanations, and reduced-eye model were prepared for Khmer One. Optional third-party audio is not distributed in this pack.

  2. JSXGraph 1.14.2 — Source · MIT license option.
  3. 3Dmol.js 2.5.5 — Source · BSD-3-Clause and bundled notices.
  4. Blockly 13.4.0 — Source · Apache-2.0 license.
  5. ts-fsrs 5.4.2 — Source · MIT license. Review schedules are saved only on the current browser/device.
  6. Bloom Player 2.22.0 — Source · MIT license. The original five-page science book has text and illustrations, without recorded narration.

Eye model distinction

gkaguirrelab/gkaModelEye is an MIT-licensed MATLAB research model. It is linked, not executed, by this website. The local simplified paraxial eye diagram is separate and is not a validated port of that model. It must not be used for diagnosis or prescribing lenses.
