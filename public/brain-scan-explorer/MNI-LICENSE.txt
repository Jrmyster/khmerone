https://github.com/niivue/niivue-demo-images/tree/f6f98294c1fa89a3a32e8a44eab92368374150a0
The upstream README identifies mni152 as derived from the ICBM 152 Nonlinear atlases version 2009. The file is retained without modification; NiiVue reorients and renders it for display. It is a reference template, not an individual patient record.
