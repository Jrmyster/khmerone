# Keyboard Garden

Keyboard Garden lives at `/typing` and teaches beginner English keyboard use through four unlocked lessons: finding keys, short words, school words and sentences. Each lesson has ten challenges. There is no timer or loss of lives. Completing each prompt grows a plant.

## Using the game

Choose a lesson, select **Let's grow**, and type into the labelled input. The QWERTY guide highlights the next key, including Shift, Space and Backspace. The F and J keys show home-position bumps. Mistakes remain visible until corrected. Escape, leaving the input or switching tabs pauses practice without discarding the current word. Paste, drops and held-key repetition cannot complete challenges.

The help button switches the main instructions to Khmer; practice content stays English. Khmer help is labelled as not teacher-reviewed. A physical keyboard is recommended; the input also supports a phone or tablet's English keyboard. Audio is not needed, and starting a lesson pauses the site's ambient audio.

## Progress and privacy

A completed lesson earns three stars at 95% accuracy, two at 80%, and one for completion. Corrected mistakes still count. Only the highest star count per lesson is stored in localStorage (`khmerone-typing-stars-v1`). Names, typed text and practice histories are not collected or sent to a server. If browser storage is unavailable, the game still works and explains that stars cannot be saved. Shared devices share stars.

The route needs an initial connection and is not advertised as offline-ready. Its illustration uses small inline SVGs; there are no external game images, audio requests or new packages. Low-data mode removes the decorative header illustration, and reduced-motion preferences disable the plant animation.

## Integration and validation

The game appears in the homepage catalog, shared Tools menu, Learning Studio and search. Search indexes all 40 prompts. Public search/navigation artifacts are regenerated by the normal build.

Validation: all 57 automated tests, TypeScript, ESLint, production build and all production route rendering checks pass. Browser checks cover a complete keyboard lesson, an incorrect letter followed by Backspace, 92% accuracy/two stars, persisted stars after reload, pause/resume with preserved input, a word, a capitalized sentence with spaces/punctuation, and Khmer help. Visual QA caught and fixed the global scenery overlapping the game. Mobile-device interaction has not been verified.
